# 🏭 Статические фабрики (GameObjectFactories)

↑ [[Паттерны]]

## Правило проекта
Все новые игровые объекты создаются **только** через статические фабрики. Запрещено инстанцировать объекты напрямую в системах/механиках.

- Все фабрики лежат в `Assets/Scripts/GameObjectFactories` — это единственная папка с таким именем; создавать другие `GameObjectFactories` запрещено.
- Единая точка создания → проще контролировать пулинг, конфигурацию, зависимости.

## Пример из проекта
`StaticElementFactory` — создаёт элементы кофе. Конфигурируется на старте:
```csharp
StaticElementFactory.CoffeeDescription = CoffeeDescription; // LoadGameComponent.Awake
```
Фабрика берёт данные из `CoffeeDescription` (ScriptableObject) и собирает игровые объекты элементов.

## Зачем
- Нет разбросанных `Instantiate` по кодовой базе.
- Создание объектов отделено от логики систем.
- Единое место для изменения способа создания (пул, варианты префабов).
