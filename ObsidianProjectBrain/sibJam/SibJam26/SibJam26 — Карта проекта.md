# 🗺️ SibJam26 — Карта проекта

Корневая нода. Unity-проект (геймплей про приготовление кофе): игрок набирает элементы, собирает рецепт, кипятит, получает результат и награды, проходит уровни-дни.

Карта построена строго древовидно: эта нода ссылается только на крупные блоки. Детали — внутри дочерних нод каждого блока.
