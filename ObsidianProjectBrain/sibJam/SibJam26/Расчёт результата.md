# 🧮 Расчёт результата (Calculate Result)

↑ [[Фичи]]

Кластер `CoffeeSystemsScripts/CalculateResultSystemScripts`.

## Что это
Подсистема, которая по итогам приготовления чашки кофе считает финальную ценность (`ResultValue`) и отправляет её в счётчик очков. Собирает данные из нескольких других систем (рецепт, кипячение, бустеры), перемножает их по формуле и передаёт управление дальше.

## Активные стейты
Работает только в `CalculateValue`. В начале `UpdateSystem` стоит ранний выход:

```csharp
if (gameSystemsHandler.StateSystem.Component.CurrentGameState != GameStates.CalculateValue) return;
```

По завершении расчёта переключает состояние на `ApproveRecipe`.

## Состав модуля
- `CalculateResultSystem` — точка входа `IGameSystem`. В конструкторе создаёт `Component` и `Mechanic`. `Initialize`/`DisposeSystem` пустые, вся работа в `UpdateSystem`.
- `CalculateResultComponent` — хранит промежуточные слагаемые и множители: `VigorSumm`, `VigorMultiplierSumm`, `TasteSumm`, `TasteMultiplierSumm`, `RecipeCostSumm`, `RecipeMultiplier`, `BoilMultiplier`, `BoostersMultiplier` (стартует `1f`), `ResultValue`.
- `CalculateResultMechanic` — собственно сбор данных и формула.

## Как работает (по коду)
1. Механика получает ссылки на сопряжённые системы через `gameSystemsHandler.GetGameSystem(...)`: `FillRecipeSystem`, `CompareRecipeSystem`, `BoilingProcessSystem`, `BoostersSystem`, `InterfaceScoreSystem`, `GameSpeedSystem`.

2. Суммирует параметры всех элементов текущего рецепта (`FillRecipeSystem.Component.RecipeContainers`):

```csharp
foreach (var container in fillRecipeSystem.Component.RecipeContainers)
{
    vigorSumm += container.ElementVigorValue;
    vigorMult += container.ElementVigorMultiplier;
    tasteSumm += container.ElementTesteValue;
    tasteMult += container.ElementTesteMultiplier;
}
```

3. Берёт множители рецепта и кипячения, а также текущий множитель бустеров:

```csharp
Component.RecipeCostSumm = compareSystem.Component.CurrentRecipe.RecipeCost;
Component.RecipeMultiplier = compareSystem.Component.CurrentRecipe.RecipeMultiplier;
Component.BoilMultiplier = boilSystem.Component.BoilMultiplier;
Component.BoostersMultiplier = boostersSystem.Component.CurrentMultiplier;
```

4. Считает итог по формуле `CalculateCoffeeValue()`:

```csharp
return (VigorSumm * VigorMultiplierSumm + TasteSumm * TasteMultiplierSumm + RecipeCostSumm)
       * RecipeMultiplier * BoilMultiplier * BoostersMultiplier;
```

То есть: (бодрость×множитель + вкус×множитель + стоимость рецепта), умноженное на множители рецепта, кипячения и бустеров.

5. Передаёт результат в счёт очков с длительностью анимации из настроек скорости:

```csharp
scoreSystem.Mechanic.UpdateScore(Component.ResultValue, speedSystem.Component.AnimationsDescription.ScoreAnimationDuration);
```

6. Переключает состояние:

```csharp
gameSystemsHandler.StateSystem.Mechanic.ChangeState(GameStates.ApproveRecipe);
```

> [!note] Бустеры считаются в собственной системе на том же стейте `CalculateValue`. Порядок обновления систем должен гарантировать, что `BoostersSystem` посчитает `CurrentMultiplier` до того, как `CalculateResultMechanic` его прочитает.

## Данные и зависимости
- **Читает из:** `FillRecipeSystem` (элементы рецепта), `CompareRecipeSystem` (стоимость и множитель текущего рецепта), `BoilingProcessSystem` (`BoilMultiplier`), `BoostersSystem` (`CurrentMultiplier`), `GameSpeedSystem` (длительность анимации очков).
- **Пишет в:** `InterfaceScoreSystem` через `Mechanic.UpdateScore(...)`; состояние игры через `StateSystem`.
- **Персистентности нет** — компонент держит только значения текущего расчёта.
