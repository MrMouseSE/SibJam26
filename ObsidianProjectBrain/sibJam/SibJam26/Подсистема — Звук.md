# Подсистема — Звук

↑ [[Инфраструктура проекта]]

## Что это

`SoundsComponentsScripts` — модуль воспроизведения звуков и музыки. Не является `IGameSystem`: это статический пул источников (`SoundInstancerController`), обёртка над миксером (`AudioMixerHandler`) и MonoBehaviour-контейнеры, вызывающие пул.

## Как работает (по коду)

`SoundInstancerController` — статический пул `SoundObjectComponent`. На старте задаётся reference-объект и миксер через Addressables:

```csharp
public static async Task SetRefObjects(AssetReference refObject, AudioMixer gameAudioMixer)
{
    _gameAudioMixer = gameAudioMixer;
    var handle = Addressables.LoadAssetAsync<GameObject>(refObject);
    await handle;
    _refSoundObject = handle.Result.GetComponent<SoundObjectComponent>();
}
```

`PlaySoundAtPosition` берёт объект из пула, ставит позицию/клип, выбирает группу миксера `"SoundsFX"`, проигрывает и через `ReturnToPool(clip.length)` возвращает объект в пул. `PlayMusicAtPosition` аналогичен, но использует группу `"Music"` и возвращает `SoundObjectComponent` для ручной остановки. `StopAllSounds`/`StopMusic` останавливают источники и возвращают их в пул, дёргая `OnObjectStop`.

`AudioMixerHandler` переводит индекс в имя параметра миксера:

```csharp
public void SetVolumeValueByIndex(int index, float volume)
{
    switch (index)
    {
        case 0: _audioMixer.SetFloat("MasterVolume", volume); break;
        case 1: _audioMixer.SetFloat("SfxVolume", volume); break;
        case 2: _audioMixer.SetFloat("MusicVolume", volume); break;
    }
}
```

`AudioContainer` (базовый MonoBehaviour) даёт хелперы `PlayRandomSound`/`PlayRandomMusic`/`StopMusic`, выбирающие случайный клип из `SoundPair[]` и делегирующие в `SoundInstancerController`. Наследники:
- `SoundContainer` — звуки `AppearSound`/`ActionSound`/`DeathSound` (массивы `AppearClips`/`ActionClips`/`DeathClips`).
- `MusicContainer` — `AreaMusic`: проигрывает случайную музыку и зацикливает её через `StartMusicLoop` на длину клипа с `CancellationTokenSource`.

`SoundType` — enum: `AppearSound`, `ActionSound`, `DeathSound`, `AreaMusic`.

## Данные и зависимости

- `UnityEngine.AddressableAssets` — загрузка reference-объекта звука.
- `UnityEngine.Audio.AudioMixer` — группы `"SoundsFX"`/`"Music"`, параметры `MasterVolume`/`SfxVolume`/`MusicVolume`.
- `Cysharp.Threading.Tasks` (UniTask) — отложенный возврат в пул и зацикливание музыки.
- `SoundObjectComponent` — носитель `AudioSource`/`Transform` и колбэка `OnObjectStop`.
- `SoundPair` — пара тип-клип, источник случайного выбора.
