# ☕ Фичи

Блок [[SibJam26 — Карта проекта]].

## Общий подход
Конкретные игровые возможности проекта. Каждая фича — отдельный модуль из систем по паттерну проекта, активный в своих игровых состояниях. Один цикл уровня проходит фичи по порядку: набор элементов → рецепт → кипячение → расчёт результата (с бустерами) → завершение уровня и награды.
