# ♻️ Жизненный цикл приложения

↑ [[Архитектура]]

Точка входа — `LoadGameComponent.Awake()`.

## Последовательность старта
1. `SoundInstancerController.SetRefObjects(...)` — подготовка звука.
2. `StaticElementFactory.CoffeeDescription = CoffeeDescription` — конфиг фабрики элементов.
3. Создаётся `GameSystemsHandler` (сразу запускает update-loop).
4. Регистрация систем: `AddStateSystem(new GameStateSystem())`, далее `AddGameSystem(...)` для всех остальных.
5. `SceneLoadingHandler.LoadScenes(ScenesLoadAtStart)` — аддитивная загрузка стартовых сцен.
6. Подписка `SceneLoadingHandler.OnSceneLoaded += SetMenuSceneActive`.
7. Инициализация инвентаря: `PlayerPrefs` по `StartAvailableElements`, `ElementsStaticInventory.LoadCurrentAvailableElements`.
8. `InitializeSystems()` — `Initialize` у всех систем.

## После загрузки сцен — `SetMenuSceneActive()`
1. Отписка от `OnSceneLoaded`.
2. У каждого scene root вызывается `InitializeSceneSystems(_gameSystemsHandler)` — связывание объектов сцены с системами.
3. `SetSceneActive(SceneNamesConst.MainMenuScene)`.
4. Настройка камеры: `CurrentCameraHolder = GetCameraHolder()`, `IsCameraUpdating = true`.

## Реестр систем (порядок регистрации)
Инфраструктура: `GameStateSystem`, `GameCameraSystem`, `GameInputSystem`, `GameSpeedSystem`.
Хэндлеры/UI: `RecipeHandlerSystem`, `InterfaceScoreSystem`, `GameTimerSystem`, `PlayerCurrencySystem`.
Элементы: `ElementsHandSystem`, `ElementsDrawSystem`, `SelectionButtonsSystem`, `ElementsRedrawSystem`, `ElementSelectionSystem`, `CompleteSelectionSystem`.
Рецепт: `FillRecipeSystem`, `CompareRecipeSystem`.
Кипячение: `StartBoilingSystem`, `BoilingProcessSystem`, `CompleteBoilingSystem`.
Результат: `BoostersSystem`, `CalculateResultSystem`, `ApproveRecipeSystem`, `ShowCoffeeSystem`.
Уровни: `LevelCompleteSystem`, `LevelHandlerSystem`, `RewardElementsSystem`, `LevelViewSystem`, `GameCompleteSystem`.

## Завершение
`DisposeSystems()` ставит `_isProcess = false`, отменяет `CancellationTokenSource` и вызывает `DisposeSystem` у всех систем.
