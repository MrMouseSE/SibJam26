# Подсистема — Твины

↑ [[Инфраструктура проекта]]

## Что это

`TweenScripts` — библиотека твин-анимаций: набор MonoBehaviour-аниматоров от базового `TweenAnimation`, группировка `TweenGroupAnimation` и проигрыватель на UniTask `UniTaskAnimationLazyObject`. Не `IGameSystem`; используется камерой, UI и игровыми элементами.

## Как работает (по коду)

`TweenAnimation` — база: хранит `Duration`, `AnimationRule` (кривую), флаги `Loop`/`IsRandomDelay`. Может анимироваться сама в `Update`, если `AnimateByUpdate`:

```csharp
public void Update()
{
    if (!AnimateByUpdate) return;
    ...
    _currentTime -= Time.deltaTime;
    if (_currentTime < 0)
    {
        if (!Loop) { AnimateByUpdate = false; return; }
        _currentTime = Duration;
        if (IsRandomDelay) SetRandomDelay();
    }
    Evaluate(_currentTime/Duration);
}
```

Конкретные аниматоры переопределяют `Evaluate(value)` / `SetForceState(bool)`. Например `PositionTweenAnimation`:

```csharp
public override void Evaluate(float value)
{
    SetPosition(Vector3.LerpUnclamped(FromPosition, ToPosition, GetRuleValue(value)));
}
```

Аналогичные есть для поворота, масштаба, цвета (спрайт/текст/material), альфы canvas, размера/позиции RectTransform, света, счётчика и движения коллайдера.

`TweenGroupAnimation` — композит: хранит `TweenAnimation[] Animations` и пробрасывает `Evaluate`/`SetForceState` во все вложенные.

`UniTaskAnimationLazyObject` — внешний проигрыватель: в конструкторе отменяет предыдущий токен и создаёт новый, в `Play` сам тикает время и зовёт `_tweenAnimation.Evaluate(...)` через `UniTask.Yield`, по завершении вызывает `AnimationCompleted`:

```csharp
while (animationTime > 0f)
{
    animationTime -= Time.deltaTime;
    float evaluateTime = baseValue + mult * animationTime / _time;
    _tweenAnimation.Evaluate(evaluateTime);
    await UniTask.Yield(cancellationToken: _tokenSourceSource.Token, true);
}
AnimationCompleted?.Invoke(this);
```

## Данные и зависимости

- `UnityEngine` — `AnimationCurve`, `Transform`, `Vector3.LerpUnclamped` и т.п.
- `Cysharp.Threading.Tasks` (UniTask) — тиканье `UniTaskAnimationLazyObject` и отмена через `CancellationTokenSource`.
- Редакторная часть: `Editor/TweenGroupAnimationEditor` — кастомный инспектор группы.
- Потребители: `GameCameraMechanic` (перелёты камеры, см. [[Система — GameCameraSystem]]), UI и игровые элементы (appear-анимации и т.п.).
