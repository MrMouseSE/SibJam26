# 🏠 Главное меню

↑ [[Фичи]]

## Назначение
Стартовый экран приложения (`MainMenuScene`). Даёт игроку запустить игровой цикл, выйти из приложения и отрегулировать громкость звука. Системы меню живут в кластере `GameSystemsScripts/MainMenuSystems`, а сцена и её UI-контейнеры — в `MainMenuScripts`.

Scene-контейнер `MainMenuSystemContainer` регистрирует обе системы меню в `GameSystemsHandler`, передавая каждой свой `MenuButtonContainer` (`StartButtonContainer`, `ExitButtonContainer`). UI-настройки звука обслуживает `SettingsHandlerContainer` поверх `AudioMixerHandler` — это MonoBehaviour-контейнеры, не отдельные системы.

## Системы
- [[Система — StartGameSystem]] — запуск игры по кнопке Start, переход в игровой цикл.
- [[Система — ExitGameSystem]] — выход из приложения по кнопке Exit.
