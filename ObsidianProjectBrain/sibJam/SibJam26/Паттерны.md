# 🧩 Паттерны

Блок [[SibJam26 — Карта проекта]].

## Общий подход
Все фичи проекта создаются по единому шаблону, чтобы код был однообразным и предсказуемым. Базовая единица фичи — **System + Mechanic + Component + Container**: система решает *когда* выполнять логику, механика — *что* делать, компонент *хранит* состояние, контейнер связывает с Unity-объектами сцены.

Дополнительные правила реализации: единая точка создания игровых объектов (фабрики) и изоляция Unity-ссылок в контейнерах сцены.
